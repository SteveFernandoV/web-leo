# Next.js Static Landing Page Starter Template

## Stack
- **Framework:** Next.js (SSG) / React
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion / CSS Animations
- **Assets:** Lucide React Icons

## Features
- Ultra-fast static rendering (`output: 'export'` compatible).
- Dark/Light mode support with `next-themes`.
- High SEO score with metadata, OpenGraph tags, and semantic HTML5.
