# Monorepo (Turborepo + pnpm) Starter Template

## Stack
- **Build System:** Turborepo (`turbo.json`)
- **Package Manager:** pnpm workspaces (`pnpm-workspace.yaml`)
- **Apps:** `apps/web` (Next.js), `apps/docs`, `apps/api`
- **Packages:** `packages/ui`, `packages/config-eslint`, `packages/config-typescript`
